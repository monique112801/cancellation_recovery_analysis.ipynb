# cancellation_recovery_analysis.ipynb

## Overview

This project analyzes appointment cancellations and patient response behavior to identify trends and improve booking efficiency.

## Key Insights

* 37% cancellation rate across 200 appointments
* No-response (38%) was the largest issue impacting bookings
* Increased contact attempts improved booking success rates
* Morning time slots showed slightly higher cancellation rates

## Recommendations

* Implement multi-touch outreach strategy (3+ attempts)
* Use automated reminders (SMS/email)
* Prioritize follow-ups for non-responsive patients
* Optimize scheduling for high-risk time slots

##  Tools Used

* Python (Pandas, Matplotlib)
* Google Colab
